## Required verification

Run from a clean, bootstrapped development environment with PostgreSQL healthy:

```powershell
uv sync --locked --all-groups
uv run python scripts/bootstrap_env.py
docker compose up -d postgres
uv run python scripts/check.py
```

The quality gate checks the dependency lock, formatting, lint, strict types, bytecode compilation,
both Django service compositions, static asset collection, migration drift/application,
PostgreSQL-backed tests with branch coverage, and package build. CI runs the same gate from a
locked clean install.
