# AG-003 acceptance evidence

This evidence maps local SOEID authentication and user administration to the repository
implementation. External ticket status remains owned by the orchestrator.

| Acceptance criterion | Evidence |
|---|---|
| Active users sign in and out with generic credential errors. | Portal login/logout views, Django local password backend, generic failure response, CSRF-protected POST logout, and PostgreSQL-backed authentication tests. |
| Browser values and identity headers cannot impersonate a SOEID. | One canonicalization boundary, UUID-backed session principal, no remote-user middleware, explicit forms, and header-spoofing tests. |
| Portal cookies are secure, host-only, HTTP-only, rotated, and absent from content. | `__Host-` session/CSRF settings, explicit `SameSite`/`Path`/`Secure` attributes, session/CSRF rotation, session-free content composition, and response-header tests. |
| Only administrators provision or change users; duplicate SOEIDs fail safely. | Transactional identity services, administrator guard, explicit forms, immutable canonical SOEID, unique database constraint, race-safe duplicate handling, and privilege-boundary tests. |
| Disabled users lose access within the documented revocation window. | `auth_version` session binding, inactive-user backend denial, disable/re-enable/reset services, and stale-session tests. The window is the next portal request. |
| Bootstrap and reset credentials are never embedded, logged, or redisplayed. | Interactive `bootstrap_admin` hidden prompts, no password argument, one-way framework hashing, password inputs with no render value, fixed audit writer, redaction tests, and operator documentation. |
| The last active administrator cannot be accidentally disabled. | PostgreSQL transaction lock on the active-administrator set, self-disable guard, last-admin policy error, and concurrent-operation coverage. |

## Verification

Run the canonical gate against the isolated lane database `agora_nor7` after starting the shared
PostgreSQL container. Do not point this worktree at the base `agora` database or print environment
secrets.

```powershell
uv run python scripts/check.py
```

The focused identity suite is:

```powershell
uv run pytest tests/test_authentication.py tests/test_services.py -q
```

The reverse-proxy SSO boundary, dashboard sharing, artifact delivery, and later MVP workflows
remain out of scope for this ticket.
