# Agora brand assets

These PNGs are web-sized derivatives of the approved Agora artwork supplied on August 27, 2026.
They preserve the source artwork without generative changes.

- `agora-wordmark-color.png`: default identity on light portal surfaces.
- `agora-mark-color.png`: compact primary mark for tight UI placements.
- `agora-mark-navy.png` and `agora-mark-white.png`: monochrome theme alternatives.
- `favicon-32.png` and `favicon-192.png`: browser and high-resolution shortcut icons.
- `apple-touch-icon.png`: installed Apple touch icon.
- `agora-app-icon-light.png` and `agora-app-icon-dark.png`: app-icon masters for light and dark placements.

Keep templates pointed at the shared `portal/partials/brand-wordmark.html` include so a later brand
color change remains a one-file update.
